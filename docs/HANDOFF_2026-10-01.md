## SECURITY FIX 2026-10-16: identities were identical on every board

"Aster" and "Bleeding Heart" showed the same identity hash. Cause: the
rweather Crypto RNG has no hardware source on nRF52, so unseeded it
runs ChaCha20 from fixed constants and `RNSIdentity::generate()` made
the same key pair on every board; those private keys are derivable from
the library source. Arduino `random()` (libc rand, unseeded) made IVs
and announce random blobs repeat as well.

Fix (`include/RNSEntropy.h`): seed the Crypto RNG from the nRF52840 RNG
peripheral (or `sd_rand_application_vector_get` when a SoftDevice is
up) with full credit plus the FICR device ID, stir every 5 s, seed
`rand()`, and take IVs / announce blobs / path-request nonces from it.
The identity file is now v2 (magic "RTID", seeded flag); a v1 file is
refused on load and the node **regenerates its identity on first boot
of this build**, logging why. `identity regen` rotates on demand.

Consequence: every RatTunnel node's identity, lxmf.delivery and
discovery hashes change on the first boot after this flash. Contacts,
RMAP entries and paths must be re-learned. This is unavoidable: the
old keys are public.

* TX cap 18 dBm drive (derivation in `RNSConfig.h`: 21 dB on-board pad,

  waking it re-initialised the panel into the GNSS inrush (dead panel).

  revisited: UART/baud verified (115200, 848 sentences/73 s), receiver

## RESOLVED 2026-10-01 evening: the T096 was transmitting ~50 dB low

Root cause: the KCT8103L's CTX line must be HIGH during transmit and LOW
for the receive-LNA path (MeshCore `LoRaFEMControl::setTxModeEnable`).
The port held CTX LOW permanently, so every transmission went out through
the FEM's receive path. Measured with the Ikoka Stick 10 cm away: the
T096 was heard at -58..-76 dBm (expected ~0..-10 dBm). Receive was
unaffected, which is why it heard everyone. The bench-day map announce
only reached RMAP because the laptop's radio was next to it.

Fix (commit after this note): `PIN_LORA_TXEN = 41` (P1.09) handed to
RadioLib via `setRfSwitchPins(NC, TXEN)` alongside DIO2-as-RF-switch, so
CTX is raised for each transmit and dropped for receive. Verified same evening: Ikoka `peers` RSSI for `27c46af4…` at 10 cm went
from -58..-76 dBm to 0..-7 dBm. The node can be redeployed.
